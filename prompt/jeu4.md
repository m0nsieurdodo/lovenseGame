# SNAKE - Lovense Arcade

## GAMEPLAY
- snake classique grid
- nourriture aléatoire
- collision = game over

---

## LOVENSE
- food → 10–20% vibration
- tous les 5 fruits → +10% global permanent
- collision → 100% vibration puis stop

---

## TECH
- grid system 20x20 ou 25x25
- useRef game loop
- keyboard direction control

---

## UI
- score
- restart
