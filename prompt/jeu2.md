# ENDLESS RUNNER - Lovense Arcade

## GAMEPLAY
- runner automatique
- saut (espace / clic)
- obstacles générés dynamiquement

---

## SCORING
- distance = score

---

## LOVENSE
- 0–500 : 10%
- 500–2000 : 30%
- 2000–5000 : 60%
- 5000+ : 100%
- saut réussi → 10%
- collision → forte vibration puis stop

---

## TECH
- requestAnimationFrame loop
- génération obstacles aléatoire
- React useRef

---

## UI
- distance counter
- game over screen
- restart

---

## STYLE
- parallax léger
- minimal arcade
