Tu es un directeur artistique senior spécialisé en UI/UX de jeux web (arcade moderne).

Je développe une suite de mini-jeux web (Next.js) avec intégration Lovense (vibrations selon le score).

## OBJECTIF
Créer une **direction artistique unique et cohérente** pour tous les jeux suivants :
- Pong
- Endless Runner
- Aim Trainer
- Snake
- Mini Casino
- Breakout
- Hub principal

Tous les jeux doivent sembler appartenir au même univers.

---

# 🎯 VISION GLOBALE

Créer une expérience :
- arcade néon moderne
- immersive mais minimaliste
- sexy/énergétique mais pas vulgaire
- très lisible (important gameplay)
- orientée feedback visuel + sonore + haptique (Lovense)

- #0b0f1a (bleu nuit profond)

- Cyan néon : #00e5ff

Couleurs secondaires :

---

# 🧱 STYLE UI GLOBAL

## Interface
- style glassmorphism léger (blur + transparence)
- contours lumineux (neon glow subtil)
- cartes arrondies (12–20px radius)
- ombres douces mais profondes

## Typographie
- style : Inter / Space Grotesk / Orbitron (accent arcade)
- chiffres (score) : font monospace ou techno
- titres : uppercase légèrement espacé

## Animations
- micro-interactions fluides (150–250ms)
- hover glow léger
- transitions soft (pas d’effet agressif)
- feedback fort uniquement sur événements gameplay

---

# 🎮 GAME UI STANDARD (OBLIGATOIRE POUR TOUS LES JEUX)

Chaque jeu doit inclure :

## HUD (Head-Up Display)
- score en haut centre
- combo en haut droite
- status Lovense en haut gauche (ON/OFF)

## Feedback gameplay
- hit → flash cyan court
- miss → flash rouge léger
- combo → glow progressif

## Game Over screen
- fond assombri blur
- score final très visible
- bouton restart stylé néon
- bouton retour HUB

---

# 🔊 LOVENSE FEEDBACK DESIGN (IMPORTANT)

Les vibrations doivent être traduites visuellement :

- faible vibration → pulse léger UI cyan
- moyenne → glow violet dynamique
- forte → screen shake léger + flash rose
- très forte → full glow + blur pulse

Le joueur doit "ressentir visuellement" la montée d’intensité.

---

# 🧭 HUB PRINCIPAL (UI CENTRAL)

Le hub doit ressembler à :
- dashboard futuriste arcade
- grid de 6 cartes jeux

Chaque carte :
- icône stylisée
- nom du jeu
- hover animation glow
- progression visuelle (score ou best score)

Ajout :
- panel settings global (Lovense intensity + toggle)
- bouton "test vibration"

---

# 🎰 SPÉCIFICITÉS PAR TYPE DE JEU

## Jeux rapides (Aim Trainer, Snake)
- UI minimaliste
- focus plein écran gameplay

## Jeux physiques (Pong, Breakout)
- UI latérale discrète

## Jeux aléatoires (Casino)
- effets lumineux plus “spectacle”
- animation plus lente et dramatique

## Endless Runner
- UI intégrée au décor (parallax HUD)
